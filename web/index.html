¿Cómo funciona?

El sistema analiza una nube de puntos 3D mediante algoritmos de agrupamiento y características geométricas para identificar estructuras de una fábrica. También permite reconstruir superficies a partir de los puntos escaneados y visualizar los resultados en tres dimensiones.

Las clases son propuestas geométricas sujetas a validación. Las superficies reconstruidas pueden incluir geometría inferida.
